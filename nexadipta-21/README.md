# NEXADIPTA 21

Website angkatan multi-page untuk SpotPulse.

## Fitur
- Beranda, Tentang, Timeline, Galeri, Kelas, Polling, Hasil Polling, Kontak
- Jam dan tanggal real-time WIB di header desktop
- Logo angkatan dari pengaturan admin
- Timeline/jadwal dapat berjumlah banyak
- Galeri dikelola admin
- Kelas mengambil data peserta aktif dari sistem utama
- Foto anggota kelas dari data peserta
- Hasil polling publik mengikuti pengaturan `show_results`

Jam/tanggal ditampilkan menggunakan waktu WIB (Asia/Jakarta) pada sisi browser pengunjung.
